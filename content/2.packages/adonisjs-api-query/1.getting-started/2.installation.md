## Requirements

- **Node.js**: `>= 24.0.0`
- **AdonisJS Core** (`@adonisjs/core`): `^7.3.4`
- **AdonisJS Lucid** (`@adonisjs/lucid`): `^22.4.2`
- **VineJS** (`@vinejs/vine`): `>= 4.4.0` _(optional, only required if you use query parameter validation)_

## Quick Installation

Install and configure the package automatically using the AdonisJS `ace add` command:

```bash
node ace add @eienjs/adonisjs-api-query
```

This command will:

1. Install `@eienjs/adonisjs-api-query` using your detected package manager.
2. Register the `@eienjs/adonisjs-api-query/providers/api_query_provider` provider in your `adonisrc.ts` file.
3. Generate the `config/apiquery.ts` configuration file.

## Manual Installation

If you prefer to install and configure the package manually, install the package with your package manager:

::code-group

```bash [pnpm]
pnpm add @eienjs/adonisjs-api-query
```

```bash [npm]
npm install @eienjs/adonisjs-api-query
```

```bash [yarn]
yarn add @eienjs/adonisjs-api-query
```

::

Then run the `configure` command to register the provider and publish the config file:

```bash
node ace configure @eienjs/adonisjs-api-query
```

## Passing the HTTP Request to the Query Builder

To read query parameters (`?filter[...]`, `?sort=...`, `?include=...`), the query builder needs access to the current AdonisJS `HttpRequest`. There are two ways to provide it:

### 1. Explicitly via `.withRequest(request)` or `$filter(request)`

Pass the `request` from your controller's `HttpContext`:

```ts [app/controllers/users_controller.ts]
import type { HttpContext } from '@adonisjs/core/http';
import User from '#models/user';

export default class UsersController {
  public async index({ request }: HttpContext) {
    // Using inline macros:
    const users = await User.query()
      .withRequest(request)
      .allowedFilters('name')
      .allowedSorts('createdAt');

    // Or using a Filterable class:
    const filteredUsers = await User.$filter(request);

    return users;
  }
}
```

### 2. Automatically via AsyncLocalStorage

If you enable [`useAsyncLocalStorage`](https://docs.adonisjs.com/guides/concepts/async-local-storage) in `config/app.ts`, the package automatically resolves the active `HttpRequest` via `HttpContext.getOrFail().request` when you omit `.withRequest(request)`:

::code-group

```ts [config/app.ts]
import { defineConfig } from '@adonisjs/core/http';

export const http = defineConfig({
  useAsyncLocalStorage: true,
});
```

```ts [app/controllers/users_controller.ts]
import User from '#models/user';

export default class UsersController {
  public async index() {
    // No need to pass `request` when AsyncLocalStorage is enabled
    return await User.query()
      .allowedFilters('name')
      .allowedSorts('createdAt');
  }
}
```

::

::tip
Passing `request` explicitly via `.withRequest(request)` or `User.$filter(request)` works regardless of whether `useAsyncLocalStorage` is enabled and is slightly more explicit in tests.
::
