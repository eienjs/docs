## How the documentation is organized

Each package maintains its own documentation next to its code, and it is published automatically on every release. That means the docs you read here always match the latest released version of the package.

## Quick start

1. Pick a package from the [packages section](/packages).
2. Follow its installation guide. Most packages are installed with your package manager and configured through the AdonisJS CLI.
3. Check the package's page for usage examples and the API reference.

## Need help?

- Open an issue in the package's repository on [GitHub](https://github.com/eienjs).
- Read the [contributing guide](/getting-started/contributing) before sending a pull request.
